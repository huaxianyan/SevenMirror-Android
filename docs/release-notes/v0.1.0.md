SevenMirror Android 把手机上的通知加密后送到你选定的浏览器，这是第一个正式版本。

## 新功能

- **通知镜像**：只发送你选择的应用，离机前按收件浏览器分别加密，中继服务器看不到正文。
- **远程操作与回复**：在浏览器里标记完成、回复或清除，手机执行前重新核对通知版本。
- **后台同步**：前台服务加应用层心跳，熄屏与深度 Doze 期间继续同步，半死连接在一个心跳周期内发现。
- **重启自恢复**：重启或进程被系统结束后自行恢复连接，不必先打开应用。
- **接收设备选择**：每台手机独立选择由哪些浏览器接收，未被选中的浏览器收不到真实内容。
- **同步网络**：Wi-Fi 与移动数据可分别关闭，关掉的网络下整条连接不存在，回到允许的网络后自动恢复。
- **暂停与恢复**：主页一键暂停发送、远程操作与快照响应，不释放后台连接，重启后保留。
- **通知稳定等待可关**：关闭后新增、更新与移除立即同步，不再等固定等待窗口。
- **权限与运行条件**：常驻页面显示实际权限状态、用途与缺失影响，从系统设置返回后重新核对。
- **电池优化引导**：首次引导与权限页说明豁免用途并提供系统入口，不作为强制条件。
- **可读的诊断**：应用私有环形时间线保存传输事件，logcat 滚掉后仍能定位失败原因。

配对身份、应用选择与接收设备在升级后保留，签名身份固定，后续版本可直接覆盖安装。

完整实现与验收记录见 [release provenance 文档](https://github.com/huaxianyan/SevenMirror-Android/blob/v0.1.0/docs/release-provenance.md)。
