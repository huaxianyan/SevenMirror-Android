这一版修掉测试通知只能留一条的问题，并把正文改成带发送时间。

## 问题修复

- **连续点击测试通知只留下一条**：发布器一直复用同一个通知 id，手机报告的是同一条通知的更新，浏览器便把已有条目就地改写，历史上永远只有一条——而测试按钮正是用来看多条通知是否都到齐的。现在每次点击都取新的 id，正文里带上发送时间，一眼能看出这是第几次发的。
- **测试通知正文**：改为「来自你手机的一条测试通知，发送于 …」，展开后仍带完整说明。
